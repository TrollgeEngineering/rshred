# rshred

An interactive, user friendly bash script for recursive shredding.

# Dependencies

1. `bash`
2. `coreutils`
3. `findutils`
4. `grep`

# How to use

1. (Optional) Create a new folder to store the repo.
2. Use `cd` to change your current directory to where you want the repository stored in.
3. Open the terminal.
4. Run `git clone https://codeberg.org/TrollgeEngineering/rshred.git` to clone the repository on your local machine.
5. Run `cd rshred` to change to repository folder.
6. Run `chmod u+x rshred` to give your user the ability to execute the script.
7. Run `./rshred`.
